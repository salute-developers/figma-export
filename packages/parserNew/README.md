# parserNew

Независимый Figma-плагин для разбора библиотек иконок. Он рассчитан в том числе на структуру файла [Icons](https://www.figma.com/design/tIN99pHRa6P44taAyr88Q0/Icons?node-id=145-1332&m=dev): категория → группы → компоненты и вложенные семейства вариантов.

Плагин работает с открытым Figma-документом через Plugin API: ссылка выше задаёт пример поддерживаемой структуры, а не загружается через REST API или внешний токен.

## Что извлекается

Для каждого найденного `COMPONENT` или `INSTANCE` плагин формирует:

- исходное и нормализованное имя;
- вариант: `regular`, `bold`, `outline`, `outline-bold` или `fill`;
- размер компонента;
- категория и путь группы из иерархии фреймов;
- страница и Figma component key, если он доступен;
- SVG.

Компоненты ищутся рекурсивно. После нахождения компонента обход его внутренностей прекращается, поэтому вложенные строительные компоненты не попадают в результат как отдельные иконки.

## Использование

1. Соберите пакет: `npm run build:parserNew` из корня монорепозитория.
2. Для публикации или постоянной локальной регистрации замените placeholder `id` в manifest на ID, который выдаст Figma при `Create new plugin`.
3. Импортируйте `packages/parserNew/manifest.json` через `Plugins → Development → Import plugin from manifest`.
4. Выделите категорию, группу или отдельную иконку. Если выделения нет, будет разобрана текущая страница.
5. Скопируйте или скачайте JSON. Двойной клик по карточке скачивает отдельный SVG.

## Разработка

```sh
npm run watch:parserNew
npm test --workspace=@salutejs/parser-new
```
