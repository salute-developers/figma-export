# parserNew

Независимый Figma-плагин для разбора библиотеки [Icons](https://www.figma.com/design/tIN99pHRa6P44taAyr88Q0/Icons?node-id=25-2&m=dev). Поиск строится по трём страницам одного документа: `16×16` (`25:2`), `24×24` (`109:8872`) и `36×36` (`145:1331`).

Плагин работает с открытым Figma-документом через Plugin API: ссылка выше задаёт пример поддерживаемой структуры, а не загружается через REST API или внешний токен.

## Что извлекается

Для каждого найденного `COMPONENT` или `INSTANCE` плагин формирует:

- исходное и нормализованное имя;
- вариант: `regular`, `bold`, `outline`, `outline-bold` или `fill`;
- размер компонента;
- категория и путь группы из иерархии фреймов;
- страница и Figma component key, если он доступен;
- SVG.

Если в Figma заполнено поле Component information, плагин разбирает из него `aliases`, `source category`, `source` и `size` и добавляет их внутрь экспортированного файла стандартным элементом `<metadata>` в формате JSON. Для instance данные читаются из main component, а для variant при необходимости — из родительского component set.

Компоненты ищутся рекурсивно. После нахождения компонента обход его внутренностей прекращается, поэтому вложенные строительные компоненты не попадают в результат как отдельные иконки.

## Использование

1. Соберите пакет: `npm run build:parserNew` из корня монорепозитория.
2. Для публикации или постоянной локальной регистрации замените placeholder `id` в manifest на ID, который выдаст Figma при `Create new plugin`.
3. Импортируйте `packages/parserNew/manifest.json` через `Plugins → Development → Import plugin from manifest`.
4. Выберите режим работы:
   - если в Figma выделена группа, плагин автоматически загрузит только иконки внутри неё; поиск будет ограничен этой группой;
   - если выделения нет, введите точное имя иконки. Несколько имён можно перечислить через запятую, например `ArrowDown, ArrowDownBold, ChevronLeft`. Плагин найдёт совпадения на всех трёх страницах и экспортирует доступные размеры.
5. Введите GitHub token и создайте PR. В PR попадёт весь найденный список: SVG будут добавлены в `packages/sdds-icons/svg/{16,24,36}` одним коммитом в новую ветку от `dev` репозитория `salute-developers/plasma`.
6. После создания PR плагин запомнит его номер и ветку. Найдите или выделите следующую группу и нажмите `Add commit with all … icons`: плагин добавит новый коммит в этот же PR.
7. Чтобы закончить работу с текущим PR и создать отдельный, нажмите `Start new PR`.
8. При необходимости JSON по-прежнему можно скопировать или скачать. Двойной клик по карточке скачивает отдельный SVG.

Каждый коммит формируется из полного результата текущего поиска или выделения, а не из одной карточки. Активная PR-сессия, как и токен, сохраняется только в `figma.clientStorage`.

Для fine-grained GitHub token нужны права `Contents: Read and write` и `Pull requests: Read and write` на репозиторий `salute-developers/plasma`. Токен сохраняется только в `figma.clientStorage`.
